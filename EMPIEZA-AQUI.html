PYTHON GRAND PRIX / GUÍA DE PUBLICACIÓN

De este ZIP a tu clase.

Versión corregida 1.0.1. Si ya subiste la anterior, reemplaza únicamente el index.html de la raíz. Conserva tu config.js si ya configuraste Google Sheets. Espera el despliegue y recarga con Ctrl + F5.

La web ya está compilada. Publícala desde el navegador y conecta tu hoja de notas una sola vez.

No necesitas instalar Node.js, npm ni Python para usar la actividad web. Node.js se utilizó para generar los archivos que ya tienes.

1. Sube la página a GitHub

  1. Descomprime el ZIP y entra en la carpeta python-grand-prix.
  2. Crea un repositorio público en GitHub. Puedes llamarlo python-grand-prix.
  3. En Add file → Upload files, arrastra el contenido de la carpeta. En el primer nivel del repositorio deben quedar index.html y config.js. Guarda con Commit changes.
  4. Si no se subió .nojekyll, créalo desde Add file → Create new file, con una línea en blanco.
  5. Ve a Settings → Pages. Elige Deploy from a branch → main → /(root) → Save.
  6. Espera la publicación y abre Visit site. Comparte ese enlace con los estudiantes cuando hayas comprobado el registro.
No subas el ZIP como un único archivo. Tampoco pongas una carpeta adicional encima de index.html. La versión 1.0.1 integra el código y los estilos en index.html. También permite abrirlo con doble clic para practicar.

Referencia: Publicar desde una rama en GitHub Pages.

2. Prepara tu hoja de notas

  1. Crea una hoja de Google Sheets vacía. Mantenla privada.
  2. Desde la hoja, abre Extensiones → Apps Script.
  3. Abre google-sheets/Code.gs con Bloc de notas, copia todo el contenido y reemplaza con él el ejemplo del editor de Apps Script. Guarda. No uses backend.template.gs.
  4. En la barra de arriba, junto a Ejecutar, abre el selector y elige la función setup. Pulsa Ejecutar.
  5. Cuando Google solicite autorización, elige Revisar permisos, selecciona tu cuenta y autoriza el acceso a Sheets. Si aparece una advertencia de aplicación no verificada, verifica que sea tu propio proyecto. El README explica esa pantalla y qué hacer si una cuenta institucional bloquea el acceso.
  6. Regresa a tu hoja: debe aparecer la pestaña Notas Python con las cabeceras.
La primera función que debes ejecutar es setup. No hay que adivinar una función ni ejecutar doPost manualmente. Esta autorización corresponde al propietario de la hoja.

3. Activa la conexión

  1. En Apps Script, abre Implementar → Nueva implementación. En el engranaje, elige Aplicación web.
  2. Selecciona Ejecutar como: Yo y Quién tiene acceso: Cualquier persona. Pulsa Implementar. Si tu institución no permite acceso anónimo, su administrador debe habilitarlo.
  3. Copia la URL de la aplicación web, que termina en /exec.
  4. En GitHub, abre el config.js de la raíz y pulsa el lápiz. Pega la URL entre las comillas vacías de googleScriptUrl.
  5. Guarda con Commit changes. Espera a que Pages se actualice y recarga la web.
window.PYTHON_GP_CONFIG = { googleScriptUrl: "PEGA_AQUÍ_LA_URL_COMPLETA_QUE_TERMINA_EN_EXEC", classId: "python-2026", courseName: "Laboratorio de Python", version: "aleatoria" };

No pegues la URL de la hoja, el ID de implementación ni un enlace terminado en /dev. No necesitas compilar después de editar config.js.

Cómo repartir las versiones A–F

Deja version: "aleatoria" para asignarlas al comenzar. Para elegir una, cambia ese valor a "A" o envía el enlace de la web terminado en ?version=A. También admite B, C, D, E y F. Una actividad ya iniciada conserva su versión.

Si quieres cambiar el código más adelante

El código React está en app/. Esos cambios sí requieren compilar, tal como explica README.md. La web que recibes ya está compilada. GitHub Pages sirve archivos estáticos; Google Apps Script se encarga de las notas.

Alcance de las pruebas

Se incluyen pruebas del banco de Python, las notas, la navegación, el renderizado de React y el servicio con Google simulado. La conexión real con tus cuentas debe comprobarse con la entrega de prueba del paso 4. No se hizo una publicación en tus cuentas ni una prueba visual en navegador.

Para instrucciones completas, mantenimiento y solución de problemas, abre README.md. Para respuestas y explicaciones, abre GUIA-DOCENTE.md.

Esta guía funciona sin conexión y admite doble clic. Puedes imprimirla para tener los pasos a mano.
